# Death Counter

A RuneLite plugin that keeps a running tally of how many times your character has died and shows the total in a small, movable on-screen counter.

## Features

- **Tracks your deaths** — every time your player dies, the counter goes up by one.
- **Persistent count** — the total is saved to your RuneLite config, so it survives logouts, world hops, and client restarts.
- **Movable overlay** — the counter is a draggable overlay you can position anywhere on the screen.
- **Custom label** — rename the counter text (default `Deaths`) from the plugin config.

## Usage

### Moving the counter

Hold **Alt** and **left-click drag** the counter to reposition it anywhere on screen.

### Resetting the counter

**Shift + right-click** the counter and choose **Reset** to set the death count back to zero.

## Configuration

Open the plugin's config panel (the gear/wrench next to it in the plugin list) to set:

- **Counter label** — the text shown in front of the number (default `Deaths`).
